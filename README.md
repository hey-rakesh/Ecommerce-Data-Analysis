# 🛒 E-Commerce Data Analysis Dashboard

An end-to-end E-commerce Data Analysis project built using Python, Pandas, Matplotlib, Seaborn, and Streamlit.

## 🌐 Live Demo

https://rakesh-ecommerce-dashboard.streamlit.app

## 🚀 Features

- Data Cleaning and Preprocessing
- Sales and Profit Analysis
- Category-wise Performance Analysis
- Top Products, Customers, States, and Cities Analysis
- Monthly Sales and Profit Trends
- Customer Age and Order Status Analysis
- Discount and Delivery Performance Analysis
- Interactive Streamlit Dashboard
- Dynamic Filters for State, Category, and Order Status

## 📊 Dashboard KPIs

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Profit Margin

## 🛠️ Technologies Used

Python, Pandas, Matplotlib, Seaborn, Streamlit, Git, and GitHub.
